ТЕСТ ЛАУНЧЕРА (отдельная копия клиента; рабочий E:\l2_client НЕ затронут)
=========================================================================

Что где лежит
  E:\l2_client_launcher_test\                 - тестовая копия клиента (без _backup_* и ruchat_fix)
  E:\l2_client_launcher_test\L2Launcher.exe    - лаунчер
  E:\l2_client_launcher_test\launcher.json     - настройки (сервер обновлений http://127.0.0.1:8765/manifest.json)
  E:\l2_launcher_testhost\                    - локальный "сервер обновлений" (только 127.0.0.1:8765)
      www\manifest.json + .sig + files\       - подписанный манифест и файлы
      start_host.bat / stop_host.bat          - запуск / остановка тест-сервера

В манифест добавлены файлы EN/RU-переключателя (русские *-k.dat, localization.ini,
SmallFont-r.gly, L2Font-r.utx). В тестовой копии их пока нет (шрифты уже есть от чат-фикса), поэтому при первом
запуске лаунчер должен сам их докачать - это и есть тест восстановления.
Внимание: localization.ini будет заменён на вариант из enru_switch (слот "Korea" + шрифт Rus4la).

0. Тест-сервер уже запущен. Если перезагружали ПК - запустите E:\l2_launcher_testhost\start_host.bat.
   Проверка: откройте в браузере http://127.0.0.1:8765/manifest.json - должен показаться JSON.

1. Первый запуск и проверка/восстановление
   - Запустите E:\l2_client_launcher_test\L2Launcher.exe
     (если SmartScreen скажет "Неизвестный издатель" -> "Подробнее" -> "Выполнить в любом случае";
      exe не подписан сертификатом).
   - Лаунчер проверит ~1505 файлов (6 ГБ, 1-3 минуты) и скачает 24 файла (10 русских *-k.dat, 13 копий *-k.dat, localization.ini).
   - Ожидается внизу: "Обновлено/восстановлено файлов: 24" и "Готово к игре".
   - Кнопка "Журнал" показывает подробности (какие файлы missing/changed).

2. Русский язык
   - Вверху справа нажмите "Русский" (интерфейс лаунчера станет русским).
   - Нажмите "ИГРАТЬ". Лаунчер запишет в system\Option.ini строку IsNative=True и запустит system\l2.exe,
     сам закроется.
   - Проверьте: меню/предметы/системные сообщения на русском; в чате набирается и отображается кириллица.
     (Опции -> Игра -> язык: "Korean" = русский, "English" = английский.)
   - Выйдите из игры.

3. Английский язык
   - Снова запустите L2Launcher.exe (повторная проверка будет быстрой).
   - Нажмите "English" -> "PLAY". В Option.ini будет IsNative=False.
   - Проверьте: игра на английском; русский чат по-прежнему печатается/читается.
   - Выйдите из игры.

4. Восстановление удалённого файла
   - Удалите, например, E:\l2_client_launcher_test\system\itemname-k.dat
     (или E:\l2_client_launcher_test\systextures\L2Font-r.utx).
   - Запустите лаунчер -> "Проверить файлы" / "Check files".
   - Ожидается: "Обновлено/восстановлено файлов: 1", файл снова на месте, кнопка "Играть" активна.
   - Дополнительно: остановите тест-сервер (stop_host.bat) и запустите лаунчер - должна быть ошибка
     "нет связи с сервером обновлений", кнопка "Играть" неактивна (так задумано). Потом start_host.bat.

Что прислать, если что-то не так
  - Скриншот окна лаунчера с открытым "Журналом".
  - Файл %LOCALAPPDATA%\L2Launcher\crash.log (если появился).
  - E:\l2_launcher_testhost\host.log (запросы к тест-серверу).

Остановить тест-сервер
  E:\l2_launcher_testhost\stop_host.bat

Удалить всё после теста (рабочий клиент E:\l2_client не трогается)
  1) E:\l2_launcher_testhost\stop_host.bat
  2) Удалить папки:  E:\l2_client_launcher_test   E:\l2_launcher_testhost
                     C:\Users\user\l2launcher_stage   %LOCALAPPDATA%\L2Launcher
  3) Удалить файл:   E:\l2_client_launcher_test_robocopy.log
  В PowerShell одной командой (после шага 1):
  Remove-Item -Recurse -Force E:\l2_client_launcher_test, E:\l2_launcher_testhost, C:\Users\user\l2launcher_stage, "$env:LOCALAPPDATA\L2Launcher", E:\l2_client_launcher_test_robocopy.log
